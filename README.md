## About me

I'm a backend developer from Latvia who started with **Ruby on Rails** and kept going deeper into the stack: **Rust** services, **Go** tooling, Docker deployments and self-hosted infrastructure I run myself.

I care about software that is **boring in production**: predictable, observable and easy to hand off. When a workflow annoys me, I build the tool that fixes it.

```ruby
class ViktorsBaikers
  def initialize
    @location  = "Latvia"
    @roots     = %w[Ruby Rails]
    @now_into  = %w[Rust Go TypeScript]
    @runs_on   = %w[Docker Linux self-hosted]
    @motto     = "If it isn't proven, it isn't done."
  end
end
```

- Currently building **Looking Glass**, a self-hosted network diagnostics console in Rust
- Maintaining **DevRites**, a disciplined engineering workflow for AI coding agents
- Always tuning: seedboxes, media servers, torrent clients, hosting panels
- Ask me about: Rails APIs, Docker, Linux servers, hosting automation
